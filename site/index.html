What it does

Zero delay
Upcoming lines are pre-translated in a 2-minute lookahead window so the translation is ready the instant the subtitle appears.
Context-aware
Lines are batched by scene so pronouns, names, and tone stay consistent across sentences — not translated in isolation.
Google Translate built in
Works out of the box with no account, no API key, and no setup required.
DeepL support
Pair your DeepL API key for higher-quality translations, especially for European languages.
Phonetics
Optional pinyin for Chinese subtitles and romanisation for Korean, shown beneath each line.
Fully customisable
Adjust font sizes, vertical position, background colour and opacity from the popup. Toggle the accent colour on phonetics and the subtitle separator.
